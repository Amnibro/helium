# Journey

Helium is part of a planned before-and-after video series on how it was built: the
language, the compiler, Gold and the graphics library, from the first version to parity
with the engines it is measured against.

Keep milestone material: the first and the latest render of every visual feature,
benchmark tables at each step, and what each stretch of work cost. Pictures live in the
shared journey archive outside the repository, named by date and subject, with one log
line per milestone (date, commit, what changed, the files kept).
